# 📚 Programação Prática

> **Repositório criado para registrar minha evolução nos estudos de programação**, reunindo exercícios, desafios e pequenos projetos desenvolvidos ao longo da minha jornada como estudante de **Análise e Desenvolvimento de Sistemas**.

A ideia não é apenas armazenar códigos, mas também **acompanhar meu aprendizado na prática**, registrar o que estou estudando e visualizar minha evolução com o passar do tempo.

---

## 🎯 Objetivo

Este repositório funciona como um **registro da minha jornada na programação**.

Aqui pretendo:

- 🧠 Praticar **lógica de programação**
- 💻 Desenvolver minha capacidade de **resolver problemas**
- 📖 Aplicar na prática os conteúdos que estou estudando
- 🚀 Criar **pequenos projetos e desafios**
- 📈 Registrar minha **evolução**
- 🔎 Identificar assuntos que preciso melhorar
- 🗂️ Manter meus estudos **organizados**
